# پیش‌بینی سری زمانی ADANIPORTS

یک پروژه کامل و سرتاسری **تحلیل و پیش‌بینی سری زمانی** برای **شرکت Adani Ports and Special Economic Zone Ltd. (`ADANIPORTS`)**.

این پروژه بر تحلیل و پیش‌بینی **میانگین قیمت وزنی بر اساس حجم (VWAP)** با استفاده از مدل‌های کلاسیک آماری سری زمانی و تکنیک‌های یادگیری عمیق تمرکز دارد.

این پروژه با دو رویکرد معماری متفاوت پیاده‌سازی شده است:

- **معماری ماژولار** – قابلیت‌ها در ماژول‌های قابل استفاده مجدد پایتون تفکیک شده‌اند.
- **برنامه‌نویسی شیءگرا (OOP)** – کل فرایند کاری با استفاده از کلاس‌های اختصاصی پیاده‌سازی شده است.

## 3. مدیریت داده‌های پرت

این پروژه از روش **دامنه بین چارکی (IQR)** برای شناسایی و مدیریت مقادیر بسیار بزرگ یا بسیار کوچک استفاده می‌کند.

آستانه پیش‌فرض برش داده‌ها برابر است با:

```python
1.5 × IQR
```
این روش محاسبات زیر را انجام می‌دهد:
```python
IQR = Q3 - Q1

Lower Bound = Q1 - 1.5 × IQR

Upper Bound = Q3 + 1.5 × IQR
```
سپس مقادیر بسیار شدید به حدود محاسبه‌شده برش داده می‌شوند.

نمونه:
```python
preparation_instance.clipping()
```

# 8.1 ARIMA

این پروژه از مدل ARIMA استفاده می‌کند:


که در آن:

- `p` = مرتبه خودرگرسیونی
- `d` = درجه تفاضل‌گیری
- `q` = مرتبه میانگین متحرک

کلاس مدل‌سازی قابلیت‌های زیر را ارائه می‌دهد:

- برازش دستی ARIMA
- AutoARIMA
- Grid Search
- پیش‌بینی
- تبدیل معکوس
- نمودارهای اعتبارسنجی
- محاسبه MAE
- محاسبه RMSE

# انتخاب مدل ARIMA

دو مدل مهم حاصل از فرایند انتخاب مدل عبارت بودند از:

```
ARIMA(0, 0, 1)
ARIMA(5, 0, 0)
```

مقایسه آن‌ها در جدول زیر خلاصه شده است:

| Criterion            | ARIMA(0,0,1)  | ARIMA(5,0,0) |
| -------------------- | ------------- | ------------ |
| Model Type           | MA(1)         | AR(5)        |
| Number of Parameters | 1             | 5            |
| AIC                  | -8320.414     | -8320.859    |
| BIC                  | **-8302.761** | -8279.667    |
| Ljung-Box p-value    | 0.99          | 1.00         |
| Residuals            | White Noise   | White Noise  |
| Complexity            | Very Low      | Moderate     |

اگرچه مدل ARIMA(5,0,0) دارای AIC کمی پایین‌تر است، مدل ARIMA(0,0,1) با استفاده از پارامترهای بسیار کمتر، BIC به‌مراتب بهتری ارائه می‌دهد.

پارامتر `ma.L1` در ARIMA(0,0,1) نیز از نظر آماری معنادار است.

بنابراین، بر اساس **سادگی، BIC، معناداری پارامتر و پیچیدگی مدل**، پروژه مدل زیر را انتخاب می‌کند:

```
ARIMA(0,0,1)
```

به‌عنوان پیکربندی ترجیحی ARIMA.

# 8.2 Simple RNN

دومین رویکرد پیش‌بینی، یک **شبکه عصبی بازگشتی ساده (Simple Recurrent Neural Network - RNN)** است.

RNN پنجره‌هایی متوالی از مشاهدات تاریخی را دریافت می‌کند و تلاش می‌کند مقدار بعدی را پیش‌بینی کند.

پروژه پنجره‌های لغزان را با استفاده از:

```python
step=10
```

ایجاد می‌کند.

به‌صورت مفهومی:

```
[t1, t2, t3, ..., t10] → t11
[t2, t3, t4, ..., t11] → t12
[t3, t4, t5, ..., t12] → t13
...
```

---

## معماری RNN

شبکه پیاده‌سازی‌شده شامل موارد زیر است:

```
Input Sequence
      │
      ▼
SimpleRNN
      │
      ▼
Dense(1)
      │
      ▼
Forecast
```

پیکربندی پیش‌فرض آموزش:

```
units=64
loss='mean_squared_error'
optimizer='rmsprop'
epochs=100
batch_size=16
validation_split=0.1
```

مدل همچنین از موارد زیر استفاده می‌کند:

- Early Stopping
- کاهش نرخ یادگیری

این Callbackها به کنترل بیش‌برازش و بهبود رفتار آموزش کمک می‌کنند.

# 11. ارزیابی مدل

این پروژه پیش‌بینی‌ها را با استفاده از دو معیار اصلی ارزیابی می‌کند.

## MAE

**خطای مطلق میانگین (Mean Absolute Error)**

```
MAE = mean(|y_true - y_pred|)
```

مقادیر کمتر نشان‌دهنده عملکرد بهتر هستند.

---

## RMSE

**ریشه میانگین مربعات خطا (Root Mean Squared Error)**

```
RMSE = sqrt(mean((y_true - y_pred)²))
```

RMSE وزن بیشتری به خطاهای پیش‌بینی بزرگ‌تر می‌دهد.

مقادیر کمتر نشان‌دهنده عملکرد بهتر هستند.

# 12. نتایج مدل

نتایج زیر از نوت‌بوک پیاده‌سازی ماژولار به دست آمده‌اند.

| Model            | MAE        | RMSE       |
| ---------------- | ---------- | ---------- |
| **ARIMA(0,0,1)** | **4.9400** | **7.2838** |
| Simple RNN       | 4.9976     | 7.3602     |

بر اساس این نتایج:

- ARIMA مقدار MAE کمتری به دست آورد.
- ARIMA مقدار RMSE کمتری به دست آورد.
- تفاوت بین دو مدل نسبتاً کم است.
- در این آزمایش خاص، **ARIMA(0,0,1)** عملکرد اندکی بهتری نسبت به Simple RNN داشت.

بنابراین، نتایج آزمایش فعلی مدل ARIMA را ترجیح می‌دهند.

> این معیارها نشان‌دهنده نتایج به‌دست‌آمده از پیکربندی فعلی نوت‌بوک هستند و نباید به‌عنوان یک نتیجه عمومی در نظر گرفته شوند که ARIMA همیشه برای این مجموعه‌داده یا برای پیش‌بینی مالی نسبت به RNN برتری دارد.

# 16. نصب

Repository را Clone کنید:

```
git clone https://github.com/SeyedRezaZibjou/Time-Series_Adaniports.git
```

وارد دایرکتوری پروژه شوید:

```
cd TIME-SERIES_ADANI_PORTS
```

یک محیط مجازی ایجاد کنید:

### Windows

```
python -m venv .venv
```

محیط را فعال کنید:

```
.venv\Scripts\activate
```

### Linux / macOS

```
python3 -m venv .venv
```

محیط را فعال کنید:

```
source .venv/bin/activate
```

وابستگی‌های موردنیاز را نصب کنید:

```
pip install -r requirements.txt
```
